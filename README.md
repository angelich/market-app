# Блог-приложение на Spring Boot

Веб-приложение «Витрина интернет-магазина» с использованием Spring Boot на блокирующем стеке технологий

---

## Команды

Сборка проекта:
`gradlew build`

Запуск проекта:
docker-compose up --build

Запуск тестов:

`gradlew test`


Приложение будет доступно по корневому пути / (http://localhost:8080/)

---

## Стек технологий

- **Java 21**
- **Spring Boot 3.1.4**
- **Spring Data JPA**
- **Spring Web**
- **H2 Database**
- **Lombok**
- **JUnit 5**
- **Mockito**
- **Gradle**
